# AllClassPlan – planned features

Ideas we want to build later (not started).

- **Alt overview**: one window with all your characters: level, gold, professions and skill,
  rested XP and where they logged out. AllClassPlan runs on every class, so it can collect this
  as each character logs in.

Other ideas from 2026-11-18, not picked yet: gear wishlist per slot (dungeon drops and quest
rewards for your plan and level), durability/repair warning before dungeons, session summary
(`/acp session`), profession cooldowns across characters.
